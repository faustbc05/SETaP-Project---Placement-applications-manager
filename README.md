# SETaP Project - Placement Applications Manager

This repository now uses topic-based folders for course-project artifacts:

- `Interview Answers/` for interview-question responses.
- `Presentations/` for slide decks and presentation files.
- `Documents/` for written reports and supporting documentation.
- `Other Materials/` for any remaining project-related files that do not fit the folders above.

Place new files in the folder that best matches their content.
